Kako koristiti bez interneta?
Dodirnite Preuzmi HTML da spremite lekciju u Preuzimanja na telefonu. Ako preuzimanje ne uspije, otvorite lekciju ili njezin GitHub repozitorij. Samostalne HTML lekcije mogu raditi bez interneta, ali vanjski zvukovi, slike i drugi resursi mogu zahtijevati vezu.

Popis javnih repozitorija zabilježen 29. 9. 2026. Za novije lekcije pogledajte sve GitHub repozitorije.
